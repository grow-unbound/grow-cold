07 — Principles
Do / Don't

✓ Do

  • Cream/parchment backgrounds in light mode — feels like a printed register
  • Noto Serif for all headings and large numbers
  • Amber-orange reserved exclusively for CTAs and active states
  • Input font at 16px always — prevents mobile zoom
  • Indian numerals: ₹2,50,000 not ₹250,000
  • 36px visual height on components, 48px tap zone via hitSlop
  • Show offline queue count — never hide network state
  • Dark elements only in dark mode (opt-in via token swap)
  • Telugu/Hindi text uses same Noto font — no fallback needed

✗ Don't

  • No pure white (#fff) backgrounds — too clinical, use cream
  • No dark nav bar in light mode — belongs in dark mode only
  • No purple or blue-grey tones — wrong emotional register
  • No decorative use of amber — only functional (CTA/active)
  • No Inter, Roboto, or system fonts for headings
  • No jargon in UI copy: SKU, sync, commit, ASN
  • No silent failures — every action needs acknowledgment
  • No touch targets below 48px tap zone — ever
  • Don't mix Noto with a Latin-only serif like Lora for i18n
